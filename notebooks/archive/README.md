# Archived notebook history

FinalCode123.ipynb is the original experimentation and model-development notebook for this project.

It contains the exploratory preprocessing work, ANN experiments, classical-model benchmark, saved-artifact demonstration, and inference prototype that informed the later structured source and Hugging Face deployment.

The notebook is preserved for provenance and education. Current reproducible execution should use the reusable source modules and scripts instead of depending on notebook cell state.
